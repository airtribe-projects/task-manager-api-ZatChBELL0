# Task Manager API

## Description
This is a simple RESTful API built with **Node.js** and **Express.js** for managing tasks. It allows users to Create, Read, Update, and Delete (CRUD) tasks using in-memory data storage.

This project was created as part of the Airtribe backend development curriculum.

## Features
- **Create a Task:** Add new tasks with a title, description, and completion status.
- **Read Tasks:** View a list of all tasks or retrieve a single task by its unique ID.
- **Update Task:** Modify details of an existing task.
- **Delete Task:** Remove a task from the list.
- **Input Validation:** Ensures required fields are present and data types are correct.
- **Error Handling:** Returns appropriate HTTP status codes (e.g., 404 for Not Found, 400 for Bad Request).

## Tech Stack
- Node.js
- Express.js
